# Face-recognition-based-Attendance-System
![Screenshot (40)](https://github.com/user-attachments/assets/967abe91-7e67-4922-84ef-e277f5df825f)
- Developed a **Face Recognition-Based Attendance System** using **Machine Learning, Python, and OpenCV** for automated attendance tracking.  
- Built a **Streamlit-based web application** for real-time face detection, recognition, and attendance logging.  
- Implemented **Dlib and OpenCV** for facial feature extraction and recognition, ensuring high accuracy and efficiency.  
- Integrated the system with a **database (SQLite/MySQL/Firebase)** for secure and scalable attendance management.
